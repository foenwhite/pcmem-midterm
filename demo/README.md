# PC-Mem 静态预录演示（固定快照）

> 汇报用副本：随 `pcmem-midterm` 仓库分发；页面可离线打开。

这是 PC-Mem 期中演示 Web UI 的**静态版**：一份固定快照 + 一段写死的问答动画。
没有后端进程、没有模型调用、没有 API Key、没有任何外部 CDN 资源，所有文件都在本地。

> **静态预录演示 · 固定快照 · 不调用模型 · 无需 API Key**
>
> 页面顶部的深绿色横幅、问答面板里的“预录”标签、以及“预录结束”提示，
> 都在说明同一件事：**这里显示的不是实时检索结果，也不是模型的实时回答。**

实时版演示需要后端与模型密钥，不在本仓库；这里只放固定快照。
本目录是期中汇报仓库内的静态副本，配套幻灯片在 `../slides.html`；实时版演示不在本仓库。

## 怎么跑

```bash
cd demo
python3 -m http.server 8780 --bind 127.0.0.1
# 打开 http://127.0.0.1:8780/
```

也可以直接双击 `index.html`（`file://` 打开）。数据内联在 `snapshot.js` 里，
页面用普通 `<script>` 加载，没有 `fetch`、没有 ES module，所以 `file://` 一样能用。

文件只有 5 个（含 favicon）：

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面结构（横幅、顶栏、资料树、图谱舞台、问答面板、快照说明弹窗） |
| `styles.css` | 原演示的白色主题样式 + 静态版的横幅 / 播放按钮 / 预录结束样式 |
| `app.js` | 图谱渲染、节点/边/文档卡片、时间线、社区视图、预录播放脚本 |
| `snapshot.js` | `window.PCMEM_SNAPSHOT = {...}`：一次性抓取的固定数据（约 180 KB） |
| `favicon.svg` | 本地图标 |

## 什么是真的，什么是假的

**真的（从运行中的演示服务一次性抓取，只读）：**

- 抓取接口只有三个：`GET /api/state`、`GET /api/documents`、`GET /api/graph`。
- 抓取时间见页面右上角「快照说明」。快照里最近一次真实构建：
  2026-11-09T20:03:33+00:00（208.6 s，模型 `deepseek-ai/DeepSeek-V4.1-Flash`，向量层 `local-hash:1024`）。
- 内容是完整的，没有裁剪：**14 个当前文档 / 16 个修订 / 65 个段落 / 146 个实体 / 202 条关系 / 6 个社区**，
  12 类实体、11 类关系全部保留；版本链（`远山项目立项书` 的 3 个修订）、
  受限许可标记、11 条文档间引用也都是快照里的真实数据。
- 节点、边、社区、时间线、项目归属、版本序号、置信度、边上的原文证据，都是抓取值。

**假的（写死的脚本，不连网、不调模型）：**

- 问答面板里的**整段问答**：问题 `远山项目的预算总额是多少？`、
  “检索”阶段的四行计数与耗时、回答 `远山项目的预算总额为 48 万元 [1]。`、
  引用 `[1]`、来源卡片、以及结束时的高亮与“预录结束”状态，全部是预录。
- 预录轨迹的固定数值（仅用于展示节奏，不是这次运行的真实遥测）：
  向量 38 候选 / 462 ms · 关键词 24 候选 / 318 ms · 图谱 17 候选 / 505 ms · 精排 8 候选 / 731 ms。
  轨迹标题写的是“预录轨迹 · 固定计数与耗时 · 非实时检索”。
- 来源卡片 `远山项目立项书 v2 · 预算` 的正文，是从快照里的抽取证据行拼起来的：
  `远山项目立项书 v2（现行） > 预算` / `总预算 48 万元` / `激光雷达租赁 18 万元` /
  `数据处理 15 万元` / `差旅与验收 15 万元`。**不是段落原文**（见下面“限制”）。
- 高亮的 7 个节点不是随机挑的：它们是快照里 `chunk_ids` 包含该预算段落 ID 的实体
  （`远山项目立项书 v2`、`预算`、`总预算`、`激光雷达租赁`、`数据处理`、`差旅与验收`、`远山`）。
  也就是说，“哪一段证据点亮哪些节点”用的是原演示的同一套映射，只是证据 ID 是预录指定的。

## 新增的按钮：▶ 播放预录演示

原演示里没有这个按钮。它在问答面板里，点击后执行一段约 5 秒的固定动画：

1. 逐字“输入”固定问题 `远山项目的预算总额是多少？`；
2. “四路并行检索 · 预录轨迹”：向量 / 关键词 / 图谱 / 精排四行依次出现，
   每行有进度条、固定候选数与固定耗时，标题处标 `预录`；
3. “证据已收集 · 准备生成”：图谱高亮 7 个相关实体，并把视图框到它们身上；
4. “生成中 · 预录回答”：逐字输出 `远山项目的预算总额为 48 万元 [1]。`；
5. 出现可点击的引用 `[1]`、来源卡片 `远山项目立项书 v2 · 预算`（含 public 许可、图层标签、score）；
6. 顶部出现 **预录结束** 面板（说明“固定脚本、无模型、无网络、无写入”）+「↻ 重播」按钮，
   播放按钮自身也变成「↻ 重播预录演示」。随时可重播，重播会清空上一轮的状态。

播放过程中**没有任何网络请求**（下面有审计记录）。点引用或来源卡片，会在图谱里高亮该文档的实体。

## 与原演示相比被移除或停用的部分

静态版没有后端，所以这些只在实时环境里成立的控件被显式停用，点击会提示原因：

- 「重建图谱」「模型设置」：虚线灰态 + 🔒，点击提示“静态版不可用：没有后端、不调用模型、也不需要 API Key”。
  设置弹窗、连接测试、密钥读写、构建进度、构建日志、社区摘要重建入口都已移除。
- 「提问 / 停止」按钮：灰态，点击提示改用「▶ 播放预录演示」。
- 「仅外发资料」「HyDE」开关：固定为快照时的状态并禁用（预录脚本不会因它们改变）。
- 「在已失效版本中查找」（版本诊断）：需要后端查询旧修订正文，静态版移除。
- 仍然可用的交互：图谱拖拽/缩放/双击适应、类型图例过滤、实体搜索、项目筛选、
  节点卡片、边卡片、文档卡片、版本链开关、时间线页、社区页。

## 限制

1. **没有文档正文段落。** 抓取的三份数据里只包含文档元数据、版本链、实体/关系与边上的抽取证据，
   不包含 `chunks` 正文。因此文档卡片显示元数据、版本链、引用关系、抽出的实体和“关系证据”，
   并明确写出“静态快照没有收录段落正文”。节点卡片的“段落证据（快照）”同理：内容是抽取到的证据句，
   不是整段原文。
2. **问答是回放，不是推理。** 换任何别的问题都不会得到回答；预录只针对 `远山项目的预算总额是多少？`。
3. **不能重建。** 图谱布局是页面加载时现算的力导向布局（并预热到稳定），但数据本身是冻结的。
4. 快照里没有用户密钥、没有 `.state/`、没有本机绝对路径（`/api/state` 的 `api` 与 `secret_file`
   字段、`sample.path` 在写文件时已剔除）。

## 自检记录

用 Chrome（headless，1440×900）跑过一遍：

- 页面只请求 4 个本地文件：`index.html`、`styles.css`、`snapshot.js`、`app.js`（+ `favicon.svg`）；
  **没有** `/api/*`、没有外部域名、没有模型端点。
- 控制台无报错；`file://` 打开同样可用。
- 播放按钮端到端跑通：问题输入 → 四行预录轨迹 → 回答逐字 → 引用/来源 → 图谱高亮 → 预录结束 → 重播。
- 节点卡片、边卡片、文档卡片、时间线、社区页、快照说明弹窗均可用。

手工核对：

```bash
grep -rniE "api[_-]?key|secret|sk-[a-z0-9]{10,}" . --include="*.html" --include="*.js" --include="*.css"
# 只应命中说明文字，不应命中任何密钥值
```
