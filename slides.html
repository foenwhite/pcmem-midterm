01  研究背景与核心问题  ·  40 秒

个人文件助手需要补充四类关系

个人电脑的信息结构，集中在向量相似度覆盖不到的关系上。

异构

  • 论文、PPT、Word、代码、数据、图片、会议记录
  • 10 种格式、4 种模态混在同一棵树里

跨目录

  • 同一个项目横跨多个顶层文件夹，最深处到第 6 层
  • 目录名只提示结构，查询仍依赖索引

多版本

  • 同一材料的 v1 / v2 / final 并存，没有版本管理
  • 新旧两版内容高度相似，向量几乎同分
检索需求普通 RAG 的缺点需要的显式表示
文档的项目归属 相似度只度量内容，不度量归属；同一主题的文档可以属于不同项目 文档级归属，三级优先级：人工 > 规则 > 模型推断
同一材料的当前版本 两个版本互为近邻，检索层无法判断先后，旧版本会被当证据引用 文档身份 + 修订行 + “当前版本”语义
跨项目的历史复用 只能取回相似段落，取不回工作历史与跨项目脉络 相似 / 引用 / 版本 / 归属四类边 + 时间线浏览
跨来源同一项目散落在多个目录与格式里，单个目录不是全集。
隐含关系归属、引用、版本先后多半不写在正文里，向量也读不出来。
动态更新新文件出现后旧结论可能失效，系统要知道该让哪条证据下线。
核心判断知识图谱在这里的作用，是让四类关系可查询、可追溯、可随新文件更新。

A · 单库同事务

段落、向量、全文索引、概念图、版本链同在一个 PostgreSQL；一个 passage 和它的图条目一起提交。不引第二个向量库或图数据库——少一个要跑、要备份、要对齐的东西。

B · 一个门面

CLI、REST /v1、MCP /mcp、Agent hook 全部调 RagService；鉴权、权限、引用、错误只有一份实现，四个入口不会各自漂移。

C · 权限先于排序

每条检索在每个检索层里先用 SQL 过滤许可、来源、时间，再排序取前 k；受限请求一律返回空集。社区摘要这类聚合文本同样受同一谓词约束。

D · 本体即约束

domain-personal 声明 12 类实体、11 类关系，每条关系限定源与目标类型；抽取提示词与结果校验共用同一份声明，约束提前到写库之前。

数据模型：一个库装下 10 张表，权限、版本、留痕都落在列上
documents来源、许可、内容指纹
chunks检索单元 + 向量 + 全文
document_embeddings文档级向量均值
document_citations引用边
kg_entities实体与证据指针
kg_relationships带引文的有向边
kg_communities社区摘要

03  我们的主要工作与创新点  ·  90 秒

创新集中在约束层：版本、可见范围与写入留痕

价值来自把文件空间的语义写进 schema、检索与写入路径。

工作做法（关键约束）证据
1 版本链与“当前版本” 身份 = 规范路径 + 内容指纹 + 成员键；修订逐条保留，默认只检索 current。旧版本必须在全部读取路径上同时消失（向量、关键字、图、社区、引用、分面、导出、读取）；revert 不被全局去重吞掉。 ADR 0014；版本用例与对抗性负例
2 项目归属三级制 人工 > 规则 > 推断。规则是有序 YAML glob，先匹配先赢；模型只能选已存在的项目，必须给出 ≥ 0.5 的置信度与原文引用，决策写入 receipt。新修订继承人工归属。 ADR 0015；受控语料归属 20/20
3 关系分 store、统一 scoped 读取 相似 / 引用 / 版本 / 归属分别存储，各自带原文证据；文档相似度只对“可见且同版本”的向量求中心，隐藏文档不影响可见文档的相似度分数。一个服务把这些关系暴露给检索与浏览。 ADR 0016；集成 279 条全过
4 抽取以证据为准 规范名后缀与最小词干、关系端点类型、字面出处三重校验：伪造别名、反向 AUTHORED_BY、被合并的无关项目、引错段落的引文，直接丢弃并计数，不进图。 ADR 0018；真实模型对照试验暴露上述四类失败
5 中文检索独立索引 英文索引与查询路径原样保留；新增 jieba 搜索模式 token 列 + GIN 索引，索引与查询用同一分词器。中文走 OR 组合，避免整句被当成一个词元。 ADR 0017；标识符类召回 0.333 → 1.000，p95 2.99 → 3.42 ms
配套两项在门面与写入路径：外发权限默认收敛——MCP / CLI 默认只放行 public 与 open_commercial，Agent 侧只拿文档 id 与状态；刷新单写者——手动、调度、hook、轮询四个渠道共用一个 advisory lock，审计只存状态与计数，路径只存哈希。

05  现存问题与后续计划  ·  40 秒

四类评测缺口与五项收尾计划

系统实现完整；对照实验尚未完成。

现存问题

评测缺口
版本链、项目归属、引用边都没有 gold；8 个公开 benchmark 里，文件间引用原生覆盖 0/8。
建图成本
一批 10 个 chunk 就要求模型输出约 6,200 token，撞上 8,192 上限后被截断、拆批重试。段落级语料（HotpotQA 约 7.4 万段）任何并发都救不回。
证据强度
F1 1.00 来自单句模板；答案检查是字符串匹配；标签没有独立人工复核；九份审阅模板全部未指派。
解析覆盖
真实用户语料尚未接入；mp3 与 ics 仍未解析；长期记忆只到模板级，没有遗忘策略的实验。
判断六项基础功能可用、链路可信；图检索与向量检索的差异尚无数据。
